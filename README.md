Personal portfolio website for Kaicheng (Kai) Chu, a Data Science & AI/ML Engineer. CS + Statistics graduate from the University of Virginia, currently pursuing an MS in Data Science at UCLA.

## Overview

A single-page portfolio built with vanilla HTML, CSS, and JavaScript.

### Sections

| #   | ID              | Content                                                                |
| --- | --------------- | ---------------------------------------------------------------------- |
| 01  | `#entry`        | Hero with animated particle canvas, glitch title, day progress tracker |
| 02  | `#professional` | Work experience cards + skills matrix                                  |
| 03  | `#projects`     | Project showcase with GitHub links                                     |
